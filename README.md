# 鼠标语音侧键助手（Mouse Voice and Side Buttons）

[English](README.en.md) · [下载 Download](https://github.com/fang775019070-rgb/mac-mouse-voice-buttons/releases)

macOS 菜单栏小工具，把鼠标中键变成 Fn，把两颗侧键变成回车和 Delete。适合语音输入、聊天回复、表单填写和轻量编辑。

| 鼠标按钮 | 映射动作 | 用途 |
| --- | --- | --- |
| 中键 / 滚轮按下（按钮编号 2） | Fn 按下，松开时释放 | 触发已绑定 Fn 的系统听写或语音输入工具 |
| 后退侧键（编号 3） | Return 回车 | 在支持回车发送的聊天框中提交；在编辑器中换行 |
| 前进侧键（编号 4） | Delete 向左删除 | 删除光标左侧字符，或删除当前选中的内容 |

不同鼠标的侧键编号可能对调，部分厂商驱动也会先把侧键转换成别的快捷键。本工具按系统收到的编号处理所有鼠标，没有按设备区分。

## 为什么这样改侧键

原来的前进、后退键适合浏览网页；语音输入时，更常用的动作是提交文字和修正识别结果。把这些动作放在拇指附近，可减少手在鼠标和键盘之间来回移动。

例如：先用中键触发语音输入，检查结果，再用后退侧键回车提交；识别错了，可先选中错误内容，再用前进侧键删除。最终是否发送、换行或确认，取决于当前应用对回车的处理。Delete 也不会自动找出错误词，需要把光标放好或选中文字。

运行期间，中键及两颗侧键的原始点击会被拦截，浏览器前进、后退和中键打开链接等功能会被替换。左键、右键和滚轮滚动保持原有行为。退出菜单栏的 Fn 工具即可恢复原始按钮。

## 安装与听写设置

1. 下载发行版 ZIP，解压，把“鼠标语音侧键助手.app”移到应用程序文件夹后打开。
2. 在“系统设置 → 隐私与安全性 → 辅助功能”中允许本应用，再重新打开。第一次授权可能需要手动把应用添加到列表。
3. 菜单栏出现 **Fn** 即表示事件监听已创建。公开版默认不设置开机启动，可自行在 macOS 登录项中添加应用。
4. 使用系统听写时，在“系统设置 → 键盘 → 听写”中开启听写，并选择 Fn 对应的快捷方式。若选择“按两次 Fn 键”，就需要双击中键；它不会把单击自动变成双击。

本工具模拟 Fn 键，本身不进行语音识别，不采集麦克风音频。第三方语音软件需要先设置为使用 Fn；系统听写的操作和隐私取决于 macOS 设置。参见 [Apple 听写说明](https://support.apple.com/guide/mac-help/use-dictation-mh40584/mac)。

发行版为本地签名，尚未通过 Apple 开发者签名与公证。如果 macOS 阻止首次打开，请先核对本仓库和校验文件，再使用系统提供的“隐私与安全性 → 仍要打开”流程。不要关闭系统的整体安全保护。

## 构建与兼容性

需要 macOS 和 Xcode 命令行工具。无需其他依赖：

```sh
zsh build.sh
```

输出 `dist/鼠标语音侧键助手.app`，包含 Apple 芯片和 Intel 两种架构。最低构建目标为 macOS 11；公开包在 Apple 芯片 Mac 和 GitHub macOS runner 上完成编译及签名校验。未对所有鼠标、Intel 硬件和 macOS 版本做实机测试。若厂商驱动接管侧键，或辅助功能权限未生效，映射可能不起作用。

## 实现与隐私

程序使用 macOS 事件监听，只订阅其他鼠标按钮的按下、松开事件，再发送对应键盘事件；不订阅键盘输入，不保存输入内容，没有网络请求和遥测。正常退出或事件监听中断时，会释放本工具仍按住的模拟按键。

此项目由原个人工具“鼠标中键模拟Fn”整理而来。公开版保留中键和侧键映射，移除了个人启动配置，并加入可重复的构建与发布流程。现有私人安装不会由本仓库自动替换。
